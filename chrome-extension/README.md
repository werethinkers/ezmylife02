# EzMyLife Shortcuts - Chrome Extension

Auto-expand your Speedy Notebook & PromptMaster shortcuts on **any website** (ChatGPT, Gemini, Grok, etc.)

## How to Install

1. Open Chrome and go to `chrome://extensions/`
2. Enable **Developer mode** (toggle in top-right)
3. Click **"Load unpacked"**
4. Select this `chrome-extension` folder
5. The extension icon will appear in your toolbar

## How to Use

1. Click the extension icon
2. Log in with your EzMyLife email & password
3. Your shortcuts will sync automatically
4. Go to any website — type a shortcut key and it **auto-expands**!

## How It Works

- Syncs shortcuts from both **Speedy Notebook** and **PromptMaster** favourites
- Works in any text input, textarea, or contenteditable field (ChatGPT, Gemini, etc.)
- Auto-syncs every 30 minutes in the background
- Click "Sync Now" in the popup for instant refresh

## Icons

You'll need to add icon files in the `icons/` folder:
- `icon16.png` (16x16)
- `icon48.png` (48x48)
- `icon128.png` (128x128)

You can use your app logo resized to these dimensions.
