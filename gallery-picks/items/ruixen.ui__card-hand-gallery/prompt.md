# Build: Card Hand Gallery

A fanned hand of image cards — hover to lift, click or flick one up to pull it out while its title and description settle in beside it.

The working code is in gallery-picks/items/ruixen.ui__card-hand-gallery/component.tsx (demo: demo.tsx). Rebuild it inside the Ezyourlife repo in its own style (docs/design.md): cream page, white cards, thick ink outlines (border-2 border-ink) with hard block shadows (shadow-block-sm / shadow-block), Unbounded headings (font-display), Hind body text, solid brand colours (bg-pink, bg-sun, bg-teal, bg-sky, bg-lime), plain words. Use our shadcn parts from src/components/ui where they fit. Keep the behaviour, keyboard and reduced-motion handling.
