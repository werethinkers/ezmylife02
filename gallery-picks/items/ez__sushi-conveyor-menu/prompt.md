# Build prompt: Sushi conveyor menu

A menu where plates ride a conveyor belt. Tap a plate to lift it and see the dish, price, details and an add button. Price tiers colour the plate rings. Props: items (id, name, price, tier 1-5, image, description, details), speed, autoplay, interval, onAdd, labels.

Copy component.tsx; it needs only React and Tailwind.
