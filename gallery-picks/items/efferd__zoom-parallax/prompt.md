# Build: Zoom Parallax

A smooth scroll effect where images zoom in at different speeds for a cinematic feel.
Perfect for hero sections or storytelling layouts that need extra visual depth.

The working code is in gallery-picks/items/efferd__zoom-parallax/component.tsx (demo: demo.tsx). Rebuild it inside the Ezyourlife repo in its own style (docs/design.md): cream page, white cards, thick ink outlines (border-2 border-ink) with hard block shadows (shadow-block-sm / shadow-block), Unbounded headings (font-display), Hind body text, solid brand colours (bg-pink, bg-sun, bg-teal, bg-sky, bg-lime), plain words. Use our shadcn parts from src/components/ui where they fit. Keep the behaviour, keyboard and reduced-motion handling.
