# Build: 3D Flip Card

An interactive card stack component with 3D hover effects and animations. Perfect for showcasing images, portfolios, or featured content.

Features
- Smooth 3D rotation effects
- Responsive design
- Interactive card selection
- Customizable card dimensions
- Configurable stack spacing
- Mobile-friendly fallback animations
- Blur effects for depth perception

The working code is in gallery-picks/items/ayushmxxn__3d-flip-card/component.tsx (demo: demo.tsx). Rebuild it inside the Ezyourlife repo in its own style (docs/design.md): cream page, white cards, thick ink outlines (border-2 border-ink) with hard block shadows (shadow-block-sm / shadow-block), Unbounded headings (font-display), Hind body text, solid brand colours (bg-pink, bg-sun, bg-teal, bg-sky, bg-lime), plain words. Use our shadcn parts from src/components/ui where they fit. Keep the behaviour, keyboard and reduced-motion handling.
