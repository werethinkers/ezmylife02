# Build: Interactive Boarding Pass Ticket Card

Interactive boarding pass ticket card with a front and back: a VIP pass with a halftone Moon and a paper boarding pass with a perforated stub you can tear off. Tilt, flip and personalise every field through props. Use it for event tickets, launch invites or a playful hero.

The working code is in gallery-picks/items/kedhareswer__lunar-boarding-pass/component.tsx (demo: demo.tsx). Rebuild it inside the Ezyourlife repo in its own style (docs/design.md): cream page, white cards, thick ink outlines (border-2 border-ink) with hard block shadows (shadow-block-sm / shadow-block), Unbounded headings (font-display), Hind body text, solid brand colours (bg-pink, bg-sun, bg-teal, bg-sky, bg-lime), plain words. Use our shadcn parts from src/components/ui where they fit. Keep the behaviour, keyboard and reduced-motion handling.
