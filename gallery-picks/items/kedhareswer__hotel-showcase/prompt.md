# Build: Hotel Showcase

Hotel listing image gallery with GSAP: a luxury hotel collection with image galleries, smooth transitions and overlay details, plus hover effects, keyboard navigation and a responsive layout. Use for travel, hospitality or real estate showcases.

The working code is in gallery-picks/items/kedhareswer__hotel-showcase/component.tsx (demo: demo.tsx). Rebuild it inside the Ezyourlife repo in its own style (docs/design.md): cream page, white cards, thick ink outlines (border-2 border-ink) with hard block shadows (shadow-block-sm / shadow-block), Unbounded headings (font-display), Hind body text, solid brand colours (bg-pink, bg-sun, bg-teal, bg-sky, bg-lime), plain words. Use our shadcn parts from src/components/ui where they fit. Keep the behaviour, keyboard and reduced-motion handling.
