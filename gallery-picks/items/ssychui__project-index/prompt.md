# Build: Project Index

A list of companies or projects where each row shows its cover beside the cursor on hover, for fund portfolios and case study pages. Part of ssych ui: https://ssych.com/library/project-index

The working code is in gallery-picks/items/ssychui__project-index/component.tsx (demo: demo.tsx). Rebuild it inside the Ezyourlife repo in its own style (docs/design.md): cream page, white cards, thick ink outlines (border-2 border-ink) with hard block shadows (shadow-block-sm / shadow-block), Unbounded headings (font-display), Hind body text, solid brand colours (bg-pink, bg-sun, bg-teal, bg-sky, bg-lime), plain words. Use our shadcn parts from src/components/ui where they fit. Keep the behaviour, keyboard and reduced-motion handling.
