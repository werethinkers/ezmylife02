# Build: LED Dot Matrix Chart Card

LED dot matrix chart card: a revenue card whose chart is a board of LED dots, lighting each day's column from the bottom with a bright top dot, sweeping on in view while the total rolls up like an odometer. For dashboards and sales stats.

The working code is in gallery-picks/items/kedhareswer__led-matrix-sales/component.tsx (demo: demo.tsx). Rebuild it inside the Ezyourlife repo in its own style (docs/design.md): cream page, white cards, thick ink outlines (border-2 border-ink) with hard block shadows (shadow-block-sm / shadow-block), Unbounded headings (font-display), Hind body text, solid brand colours (bg-pink, bg-sun, bg-teal, bg-sky, bg-lime), plain words. Use our shadcn parts from src/components/ui where they fit. Keep the behaviour, keyboard and reduced-motion handling.
