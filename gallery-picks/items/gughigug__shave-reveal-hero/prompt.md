# Build: Shave Reveal Hero

Interactive hover-reveal hero — drag a blade across a bearded portrait to shave it, with synthesized sound. Full light/dark theme support and keyboard navigation. Zero dependencies.

The working code is in gallery-picks/items/gughigug__shave-reveal-hero/component.tsx (demo: demo.tsx). Rebuild it inside the Ezyourlife repo in its own style (docs/design.md): cream page, white cards, thick ink outlines (border-2 border-ink) with hard block shadows (shadow-block-sm / shadow-block), Unbounded headings (font-display), Hind body text, solid brand colours (bg-pink, bg-sun, bg-teal, bg-sky, bg-lime), plain words. Use our shadcn parts from src/components/ui where they fit. Keep the behaviour, keyboard and reduced-motion handling.
