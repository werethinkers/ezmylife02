# Build: Curtain Split Hero

A theatrical stage-reveal hero component where a stacked deck of cards splits symmetrically apart into curved vertical wings to unveil central typography.

The working code is in gallery-picks/items/daiwiikharihar__curtain-split-hero/component.tsx (demo: demo.tsx). Rebuild it inside the Ezyourlife repo in its own style (docs/design.md): cream page, white cards, thick ink outlines (border-2 border-ink) with hard block shadows (shadow-block-sm / shadow-block), Unbounded headings (font-display), Hind body text, solid brand colours (bg-pink, bg-sun, bg-teal, bg-sky, bg-lime), plain words. Use our shadcn parts from src/components/ui where they fit. Keep the behaviour, keyboard and reduced-motion handling.
