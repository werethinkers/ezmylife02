# Build: DoctorLiveChatCard

A modern, responsive UI component to showcase a doctor’s profile for live consultation. It highlights real-time availability, rating, specialty, and enables patients to instantly join a chat or bookmark the doctor. Built for both light and dark modes with a sleek, accessible design.

The working code is in gallery-picks/items/ruixen.ui__doctor-live-chat-card/component.tsx (demo: demo.tsx). Rebuild it inside the Ezyourlife repo in its own style (docs/design.md): cream page, white cards, thick ink outlines (border-2 border-ink) with hard block shadows (shadow-block-sm / shadow-block), Unbounded headings (font-display), Hind body text, solid brand colours (bg-pink, bg-sun, bg-teal, bg-sky, bg-lime), plain words. Use our shadcn parts from src/components/ui where they fit. Keep the behaviour, keyboard and reduced-motion handling.
