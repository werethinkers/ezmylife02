# Build: FAQ Accordion Section

FAQ accordion section set in one ink on one paper: a display headline cut by a stencil slit that lifts clear on hover, live search across questions and answers with matches highlighted, and rows that flood with ink edge to edge as they open. A real accessible accordion with keyboard navigation, deep links per question and Copy link. Single or multiple open, four presets, light and dark.

The working code is in gallery-picks/items/kedhareswer__slit-type-faq/component.tsx (demo: demo.tsx). Rebuild it inside the Ezyourlife repo in its own style (docs/design.md): cream page, white cards, thick ink outlines (border-2 border-ink) with hard block shadows (shadow-block-sm / shadow-block), Unbounded headings (font-display), Hind body text, solid brand colours (bg-pink, bg-sun, bg-teal, bg-sky, bg-lime), plain words. Use our shadcn parts from src/components/ui where they fit. Keep the behaviour, keyboard and reduced-motion handling.
